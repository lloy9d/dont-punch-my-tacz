When you hold a TACZ or SuperbWarfare gun with Punchy installed, the gun visually duplicates/glitches on your screen. It looks like you're holding two guns at once, even though you only have one

The Punchy mod already has a fix for this: press **F8** and add the gun to the blacklist. This works, but you have to do it every time. This mod does that step for you automatically

**Note:** It is just a small helper mod

## Which File Do I Download?

| File | Mod Loader | Minecraft |
|---|---|---|
| `dont-punch-my-tacz-vX.Y-1.21.1.jar` | **NeoForge** | 1.21.1 |
| `dont-punch-my-tacz-vX.Y-1.20.1.jar` | **Forge** | 1.20.1 |

On Modrinth, pick the file that matches your mod loader. On GitHub, both files are on the same [release](https://github.com/lloy9d/dont-punch-my-tacz/releases)

## How to Install

1. Pick the file for your mod loader and Minecraft version (see the table above)
2. Put it in your `mods` folder
3. Every player needs this mod. The server does **not** need it

### NeoForge 1.21.1

- **NeoForge**
- **Punchy** (the NeoForge version)

### Forge 1.20.1

- **Forge**
- **Punchy** (the Forge version)

### Optional (only used if you have them installed):

- **TACZ** → all guns
- **SuperbWarfare** → all guns, grenades, and a few special items
- **Create** → potato cannon, extendo grip, worldshaper
- **Create Simulated Aeronautics** → plunger launcher
- **Power Grid** → portable saw, drill, electrozapper

## What This Mod Does

It automatically adds the items above to Punchy's F8 blacklist. It does **not** change any other Punchy settings
